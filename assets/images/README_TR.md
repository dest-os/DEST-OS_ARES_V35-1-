# ARES Ekran Görselleri

Bu klasörde ARES'in kullanıcı tarafından sağlanan gerçek tasarım referansları bulunur.

- `ares_ana_ekran.png` — 1. görsel: ARES ana ekran / sanal şirket ve çalışma ofisi.
- `ares_etkilesim_referansi.png` — 2. görsel: Ana ekran ile tıklama yönlendirmelerini gösteren referans.
- `ares_chat_ekrani_referans.png` — 2. görseldeki sol bölüm: DİNLEYİCİ alanına tıklanınca açılacak ARES Chat ekranı referansı.
- `ares_sistem_api_ayarlari_referans.png` — 2. görseldeki sağ bölüm: merkez göz logosuna tıklanınca açılacak Sistem & API Ayarları ekranı referansı.

Görseller yeniden tasarlanmadı veya üretilmedi; kullanıcı tarafından sağlanan görsellerden doğrudan alınmıştır.
