# Android Katmanı

Bu klasör ARES Flutter uygulamasının Android çalışma katmanıdır.

- Paket: `com.destos.ares`
- Minimum Android sürümü: API 23
- Java: 17
- Gradle: 8.9
- Android Gradle Plugin: 8.7.3

Mağaza imzası ve gizli anahtarlar GitHub Secrets üzerinden yönetilecektir; repository içine gizli anahtar konulmayacaktır.
