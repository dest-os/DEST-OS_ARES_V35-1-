# DEST-OS ARES V24 – Android Cihaz Entegrasyonu

V23 kümülatif temelinin üzerine Android cihaz entegrasyonunun domain/application/infrastructure sözleşmeleri eklendi.

Kapsam: cihaz bilgisi, izin sözleşmeleri, cihaz runtime yaşam döngüsü, kaynak snapshot, kesinti/kurtarma durumu ve Android gateway adapter temeli.

Gerçek Android platform API bağlantıları daha sonraki üretim/adapter aşamalarında güvenli biçimde bağlanacaktır. Bu sürüm gerçek cihaz izni vermiş veya arka plan servisinin çalıştığını iddia etmez.
